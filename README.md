## 🎮 Projeto atual

**Savepoint**: uma plataforma para avaliar, comentar e recomendar jogos, inspirada no Letterboxd e no MyAnimeList.

- 👤 Perfil de usuário com os jogos que você jogou e as notas que deu
- ⭐ Avaliações e reviews de jogos
- 🤝 Visitar o perfil dos amigos para ver o que eles estão jogando e recomendando
- 💬 Uma comunidade dentro de cada jogo para tirar dúvidas, conversar e fazer amigos
- 🌗 Modo claro e escuro

> 🚧 Em desenvolvimento: primeiro uma versão de testes com amigos, depois aberta ao público.
